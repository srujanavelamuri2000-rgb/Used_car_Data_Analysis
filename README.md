**Used Car Data Analysis using Python**
**Project Overview**
This project explores a dataset of used car listings to understand vehicle characteristics and asking prices using Python.
**Objective**
To analyse used car listings and explore how factors such as brand, manufacturing year, vehicle age, mileage, transmission and fuel type relate to asking prices.
**Tools and Technologies**
Python
Jupyter Notebook
Pandas
NumPy
Matplotlib
**Dataset**
The dataset contains 9,582 used car listings and 11 columns, including:
Brand
Model
Year
Age
Kilometres Driven
Transmission
Owner
Fuel Type
Posted Date
Additional Information
Asking Price
**Data Cleaning**
The following steps were performed:
Checked dataset structure and data types.
Identified missing values.
Converted asking price and kilometres driven into numerical formats.
Identified 801 duplicate records.
Removed duplicate records, resulting in 8,781 records.
Retained missing mileage values for further analysis.
**Exploratory Data Analysis**
The project explores the distribution of used car asking prices and other vehicle characteristics.
**Key Observations**
The median asking price is approximately ₹5.9 lakh.
The average asking price is approximately ₹10.4 lakh.
Asking prices show considerable variation across listings.
**Conclusion**
This project provided practical experience in data cleaning, exploratory data analysis and statistical analysis using Python and Pandas. It also helped develop an understanding of how data analysis can be used to explore used car market trends.
**Project Status**
Beginner-level data analysis project. Further exploratory analysis and visualisations are being developed.
